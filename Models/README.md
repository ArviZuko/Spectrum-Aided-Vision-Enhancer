# Additional downloadable SAVE models

The curated Git tree includes selected compact models. The folders below link to separate ZIP packages for the remaining model families and Kvasir weights. Each ZIP contains the original `Models/...` paths; extract it at the repository root. Multipart packages provide all parts and joining instructions in their folder README.

[Browse all packages in the Release](https://github.com/ArviZuko/Spectrum-Aided-Vision-Enhancer/releases/tag/v1.1-remaining-models).
